运行入口：`scripts/test-demo.ps1`，或设置 `DRISSIONPAGE_BROWSER` 后运行 `go test -count=1 -timeout 2m -v -run '^TestAsyncHTMLDemo$' .`。

## 已发现并修复

- 新标签页激活后，原标签页的点击等待后台动画帧而长期不返回。Go 鼠标操作改用有超时的可见性、滚动及命中检查。
- 控制台对象参数原先不能读取内容，现在可生成有限深度快照；循环引用、访问器和截断有明确标记。
- 补齐点击触发文件选择器的上传功能。
- 测试服务显式提供 `index.html`，避免 Go FileServer 自动重定向使历史记录与原服务不同。

## 验证边界

这 18 组覆盖页面主要事件，但不是原 Python A–E 五组中 488 条断言的逐条移植。窗口原生隐藏/显示、全部定位边界、所有配置字段及其他剩余兼容项仍见 MIGRATION.md。不能将 HTML 回归通过视为全项目 100% 迁移完成。
